# Webbplatsens ikoner

`Ikon_fotokartgenerarator.png` är originalet (1254 × 1254 pixlar).
De mindre PNG-filerna är nedskalade från originalet med Lanczos-filtrering:

- 16, 32 och 48 px: webbläsarikoner.
- 180 px: Apple touch-ikon.
- 192 px: större webbplatsikon.
- 512 px: bild i länkförhandsvisningar (Open Graph och Twitter Card).
- `favicon.ico`: innehåller 16, 32 och 48 px.

Referenserna finns i `index.html`. Delningsmetadata använder den antagna
GitHub Pages-adressen `https://tomasfalk64.github.io/fotokarta/`.
Om sidan publiceras på en annan adress behöver `og:url`, `og:image` och
`twitter:image` uppdateras till den publika adressen. Bildadresserna ska vara
absoluta så att tjänster som hämtar länkförhandsvisningar kan läsa dem.
